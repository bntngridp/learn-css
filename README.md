# Learn CSS

Kumpulan kode latihan pembelajaran CSS yang dipisahkan dari repositori `mayyaisbetter/learn-frontend`.

## Struktur Materi

- `belajar-css-dasar/` - Selector, warna, tipografi, box model, background, border, list, tabel, form, opacity, filter, dan cascade layer.
- `belajar-css-layout/` - Display, normal flow, float, positioning, Flexbox, CSS Grid, subgrid, multiple column, dan media query.

## Cara Menjalankan

Buka langsung berkas `.html` yang diinginkan melalui browser atau gunakan ekstensi Live Server pada editor kode.
